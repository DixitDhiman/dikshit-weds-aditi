# Dikshit Weds Aditi

A romantic wedding invitation website for the celebration of Dikshit and Aditi.

## Overview
This project is a static, mobile-friendly wedding invitation page built with HTML, CSS, and JavaScript. It includes a warm floral theme, animated opening envelope, event details, gallery, and background music for a polished digital invite experience.

## Files in this folder
- `index.html` — Main wedding invitation page with all layout, styling, and interactivity.
- `bride.jpeg` — Bride photo.
- `groom.jpeg` — Groom photo.
- `couple-hero.jpeg` — Hero image for the couple.
- `gallery1.jpeg` to `gallery4.jpeg` — Wedding/gallery images.
- `wedding-music.mp3` — Background music used on the page.

## Features
- Elegant wedding invitation design
- Animated envelope reveal on load
- Event details and schedule section
- Photo gallery
- Music toggle control
- Responsive layout for mobile devices
- Confetti celebration effect

## How to view the project
Open `index.html` directly in a browser, or run a small local web server from this folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes
- This is a front-end static site; there is no backend or database.
- To personalize text, names, dates, venue, or images, edit the relevant sections in `index.html` and replace the image files as needed.
- External resources such as Google Fonts and CDN scripts are used for styling and confetti effects.

## Suggested customization
If you want to use this for your own event:
1. Update the names and wedding date in `index.html`.
2. Replace the photos with your own images.
3. Edit venue, RSVP, and event details to match your celebration.
4. Optionally replace the music file with your own track.
